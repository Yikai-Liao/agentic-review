# 代码行为证明

用于代码层的意图/语义审查，也为安全、可靠性、性能或测试候选提供直接相关的行为依据。不另建 ledger、工作稿或发布流程。

## 什么不构成生产 finding

- CI 能稳定直接发现的格式、编译、类型或测试错误；同一变化中 CI 难以发现的独立生产风险仍应调查。
- 单纯缺测试、覆盖率、注释、文档或 benchmark。
- 命名、布局、架构偏好、anti-pattern 或危险形状本身。
- 没有真实路径、规模及成本差分的性能猜测。
- 当前证据无法支持、必须依赖尚未取得的运行结果才能确定的问题。

明确委托的改进和验证审计使用其独立证明，不通过降低生产门槛容纳建议。

## 生产候选的代码级证明

共同门槛之外，需要：

1. **归因**：delta 指出本次引入、扩大或重新激活原因；audit 指明既有机制，不能冒称 PR 引入。
2. **可达**：仓库代码和契约支持现实入口与最小触发。
3. **违约**：当前结果违反可独立恢复的产品、API、数据、安全、可靠性或操作契约；性能用 [成本证明](performance.md)，不强求显式 SLA。
4. **实质影响**：改变观察者的生产结果、判断、下一步操作或故障恢复，不只是可以观察到差异。
5. **可操作**：绑定所审版本的最小根因位置并说明恢复的约束，不要求唯一补丁。

生产结果包括返回、状态、持久化、副作用、延迟、资源、错误分类、失败对象/原因、修复指引和重试信号。诊断错报必须说明合理消费者会采取什么错误操作、无效重试、重复提交或额外排查；机器信号需真实消费路径。“用户可能困惑”不足。保持对象、类别、约束与修复方向的等价改写不报。

HTTP 状态、是否拒绝或写入保持相同，只能反证这些维度，不能反证返回内容和诊断语义错误。

## 调查方法

从完整受托变化恢复相关独立契约；读取必要上下文与直接依赖，追踪：

```text
入口 → 校验/转换 → 决策 → 状态/副作用/资源
     → 返回/错误/重试/清理 → 实际消费者
```

分别核对生产行为与同期测试、fixture、snapshot、mock、helper 的依据；共享常量或同批文档一致不能自证正确。字段追到实际消费的值和结构，状态追到观察与恢复路径；写入成功、schema 一致或 helper 存在不足。

删除、放宽的 guard、权限、默认值、过滤、错误、事务、重试、清理、分页与缓存同样调查。为新增、改变或依赖的保护选择能区分承诺的合法/非法、可恢复/终止等真实边界，推演原始值、转换、分支和消费结果。解析成功不证明原文满足规则，同名状态不证明操作权限相同。

恢复路径仍须属于同一逻辑操作；没有有效授权，不能为了成功静默改租户、业务日期、范围、身份、幂等键、顺序或载荷。约束仍满足、最终成功或测试同步变化不证明语义等价。

必要直接路径已闭合才结束；可读路径没追完不能以未知提前停止。消费者不可得则记录具体限制，不假设兼容。成本或测试证据按代码层入口触发，在同一 batch 共享，不重扫全 diff。

## 最强反证与记录

检查上游校验、下游保护、合法例外、helper 已有分页/缓存/批处理、精确值/顺序/调用次数是否真实契约、规模限制、原基线、已接受决定及同根因历史。替代需保持权限、顺序、事务、错误和返回语义。

每个存活候选保留 expected / actual / trigger / observer / substantive delta / 当前归因 / strongest rebuttal / 成立或失败门槛。没有成立候选正常；严重度在证明后按 [代码标签](../code.md) 判断。每个受影响结果都应有契约、实现或遗漏路径、消费证据及保护推演，或明确无法完成部分；状态与结束只使用共同规则。
