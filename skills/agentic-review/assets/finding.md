# 问题卡模板

不是每条都要写长文；最小问题用一个短段也可以。性质、代码展示标签和状态分别记录，规则以 [结论契约](../references/findings.md) 为准，模板不增加门槛。

```text
F1 [性质；侧重点/适用代码标签；处理优先级；相关所有者]：触发 → 后果

问题：在什么实际条件/当前承诺下，预期是什么，当前如何不同。
依据与机制：版本定位、独立依据、最短因果路径；最强反证为何不成立。
处理完成条件：应恢复的约束/应解决的决定，不强制唯一方案。
最小验收：原见证现在得到什么结果，直接相邻的合法行为如何保持。
边界：静态推演/已有实测/尚待验证；需要上层决定时限定影响范围。
```

improvement 额外保留真实任务、可行替代及迁移代价；verification-gap 保留局部错误、旧验证无法区分与新增观察；decision 保留必须现在决定的理由。
