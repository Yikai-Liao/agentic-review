# 请求超出当前任务权限的决定

当前编写者无法在已有要求和授权内解决问题时，将需要决定的部分交给相应上层或有权者，而不是提交全部调查日志或请求笼统批准。

```text
关联的 F 编号，问题在哪一层发现：
哪项上层要求或前提不成立，原始依据是什么：
最小反例是什么，为什么不能在当前权限内修好：

真正可行的选择及代价：
- 保持原要求，需要增加或改变什么？
- 改变要求，会失去什么，需要谁明确接受？

谁有权决定：
会影响哪些交付或任务：
哪些已获授权的部分仍可独立继续：
当前需要回答的具体问题或补充事实：
```

只列实际可行的选择，不凑选项。如果只需调查事实且已有授权，就交给相应执行者；缺少价值取舍时才找决定者。

返回的新决定带上来源和适用范围。审查者据此重新检查受影响的前提，不自动宣布全部下级任务已获执行批准。
