# 修复返回（构造者 → Reviewer）

这是给另一个构造/执行任务的交接说明，不授权 Reviewer 修改目标。

```text
本次修复基于：旧目标版本、原 Review、相关有效决定。
新目标版本：

处理 F1：
- 改变了哪个机制：
- 原 finding 的关闭条件现在为什么得到满足：
- 哪些相邻合法行为必须保持：
- 实际执行的验证、版本、环境及原始结果：
- 没有执行/不能证明的部分：

修复之外的新增变化：
上层承诺或已接受代价是否改变：
仍未解决或请求接受的具体问题：
```

构造者只修获授权范围，不为使 finding 消失而改目标、收缩合法输入或删除真实验证。不同于建议方案的正确修复可以接受。构造者不能自行标记“独立审查通过”；Reviewer 根据新版证据更新状态。
