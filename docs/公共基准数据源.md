# 公共 Review Benchmark 数据源

首批外部样本采用 AACR-Bench：固定上游 commit `b3072489eace26efca8bcf2b1ac6a24ba64f82c1`，从 TypeScript 的 `Defect`、`Security` 分类中选择 5 个 base/head SHA 均可获取的样本。

选择理由：

- Apache-2.0；
- 标注文件约 1.1 MB；
- 含 base/head SHA、路径、行号、分类和专家确认 finding；
- 覆盖多语言，后续可验证跨仓库泛化；
- 不要求容器或安装被审仓库依赖。

限制：公开 issue 已记录部分历史 SHA 不可获取，生成 corpus manifest 时必须逐个验证；LLM semantic matcher 不是绝对真值，重要争议仍需人工裁决。

SWRench 固定到 `67ae1d4395ac05f800d62b0e13678eadeb9fa5c7`，用于 clean/noise 测试。c-CRAB 固定到 `856dfa3102b8996d168c4f195217b7603e1d1bc6`，可用于内部临时评测和后续可执行测试验证；由于数据仓库没有明确许可证，只临时拉取，不把原始数据或评论提交到本仓库。Martian 缺少固定 base/head/path/line，不作为首批主数据。

首批筛选结果保存在 [`benchmark/corpus.json`](../benchmark/corpus.json)，expectation 只供 evaluator 使用，不进入 Reviewer context；不提交运行产物。
