# Review 规则演化方法

Darwin Skill 只用于本地实验方法，不进入云端 Review Engine 运行时。

每轮只改变一个变量，并执行：

1. 创建或隐藏一个真实缺陷。
2. 人工确认门 A：确认缺陷成立、方向正确、base 正常/head 错误、样本未泄漏答案。
3. 在相同 sealed corpus 上运行 baseline 与 candidate。
4. 使用同一个 judge 在一次调用中成对比较两版结果；本地同时最多运行两个 sub-agent。
5. 修改通用 prompt 或规则。
6. 人工确认门 B：确认规则具有通用性且没有写入 fixture 特征。
7. 重跑正例、负例和 holdout；退化立即回滚。

绝对 LLM 分数只用于粗排，不用于 keep/revert。关键安全问题漏报、clean case 噪声上升或稳定性下降都禁止保留修改。
