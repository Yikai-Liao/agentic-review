# 通用化行为案例

本目录提供方法与范围验收用例，实际运行结果另文记录。69 例覆盖需求、架构、计划、代码及跨层复核；不得因文件齐全而计为通过。与上级目录的表达评测并列，不替换其工具、用例和历史结果。

C09/C10 是关联外部记录的回归材料：计划与标签、范围内接受、具体修复依据、状态不明、无关同名记录，以及扩大接受范围和重新激活已修问题。输入与预期分离；它们已纳入下面的首轮比较，但结构检查和小组评分均不等于完整行为验收。

D01—D06 检查批量入口授权、派生副本与恢复保护、取证受阻交接、覆盖清单漏项、资源标识转换和窄审范围。生成器只读取输入，预期保存在独立文件中。

[路径调查与覆盖反查首轮结果](investigation-results.md)：8 例两版共 16 份报告已生成；匿名评判因编排错误无效。D03 的补证方向正确，阻断措辞偏重；后续已调整表述要求，尚未重跑模型比较。

[Skill 可读性改写首轮结果](readability-results.md)记录了 12 例新旧生成与三评委比较：原始评分候选 12/12、基线 11/12，逐例多数偏好为 2 胜、2 负、8 平。该轮没有证明整体改善，且有评判协议偏差；其余案例与完整中央流程仍未验证。

- [cases.json](cases.json)：ID、分组和相对仓库根目录的输入路径。
- `inputs/`：任务、原始依据、目标和必要历史，供被测 Reviewer 读取。
- [expectations.json](expectations.json)：只给评估者的预期，不能提供给被测 Reviewer。
- `runs/`：本地原始运行输出与证据，Git 忽略；不进入生产 prompt。

每例用独立新上下文，固定并记录实际 skill/中央控制面版本、模型和推理档位、目标版本、输入及输出哈希、工具轨迹、成本、评分者与具体依据。代码兼容比较运行完整的旧中央组合和新中央组合；新的领域案例单独验证，不让旧代码 Reviewer 承担它没有承诺的能力。

检查正确机制与归因、错误类型/严重度、禁止的误报、权限、覆盖和复核状态。输入不足则修正材料并重跑所有比较版本，不用 gold 补充被测任务。合成静态探针不是实际运行目标代码，也不能替代真实 PR、多轮历史恢复或 compaction 的模型回归。
