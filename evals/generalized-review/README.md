# 通用化行为案例

本目录是方法与范围验收材料，不是运行结果。63 例覆盖需求、架构、计划、代码及跨层复核；不得因文件齐全而计为通过。与上级目录的表达评测并列，不替换其工具、用例和历史结果。

C09/C10 是关联外部记录的回归材料：计划与标签、范围内接受、具体修复依据、状态不明、无关同名记录，以及扩大接受范围和重新激活已修问题。输入与预期分离；新增材料尚未运行模型评测，结构检查不等于行为验收。

- [cases.json](cases.json)：ID、分组和相对仓库根目录的输入路径。
- `inputs/`：任务、原始依据、目标和必要历史，供被测 Reviewer 读取。
- [expectations.json](expectations.json)：只给评估者的预期，不能提供给被测 Reviewer。
- `runs/`：本地原始运行输出与证据，Git 忽略；不进入生产 prompt。

每例用独立新上下文，固定并记录实际 skill/中央控制面版本、模型和推理档位、目标版本、输入及输出哈希、工具轨迹、成本、评分者与具体依据。代码兼容比较运行完整的旧中央组合和新中央组合；新的领域案例单独验证，不让旧代码 Reviewer 承担它没有承诺的能力。

检查正确机制与归因、错误类型/严重度、禁止的误报、权限、覆盖和复核状态。输入不足则修正材料并重跑所有比较版本，不用 gold 补充被测任务。合成静态探针不是实际运行目标代码，也不能替代真实 PR、多轮历史恢复或 compaction 的模型回归。

准备阶段对更早快照曾运行 Luna high 14 例，作者评分通过；它早于章节导航、skill 改名及中央迁移，不能声明本分支已通过。运行产物未迁入，当前目录仅提供可重跑的材料，不合并新的模型结果到既有表达评测的 `results.tsv`。

结构和中央接入检查使用 `pnpm check`、`pnpm test`；模型比较需要另行执行。新增层级及默认中央范围见 [实验说明](../../docs/generalized-review.md)。
