# 审查任务 D01

使用 agentic-review，对代码快照 e2 的导出权限做整体审计。

## 宿主与来源

你是未参与编写目标的独立 Reviewer。下文是固定版本的相关合成材料；除明确缺失项外，判断所需事实均已给出。只读目标，可保存私有审查记录；没有运行目标代码、修复、委派、联网或发布权限。用户明确决定可作为业务依据。

## 材料

用户约定 U1：用户只能取得自己租户的数据；单条和批量导出遵守同一规则。

快照 e2：
- `getOne(actor, id)` 调用 `store.read(actor.tenant, id)`。store 以 tenant 与 id 联合查询，不匹配就拒绝。
- `exportMany(actor, ids)` 是已登录普通用户可直接调用的新入口。它逐项调用 `store.readById(id)`，将得到的完整记录写入响应。
- `readById` 只按全局唯一 id 查询。用户 A 知道租户 B 的记录 id `b17`；请求体接受这个 id，返回前没有其他归属过滤。
- 日志只记录请求号；下载响应直接返回给发起者，不经过另一层服务。
