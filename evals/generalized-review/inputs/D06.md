# 审查任务 D06

使用 agentic-review，只审代码快照 q2 的批量读取性能，不审安全或其他专项。

## 宿主与来源

你是未参与编写目标的独立 Reviewer。下文是固定版本的相关合成材料；除明确缺失项外，判断所需事实均已给出。只读目标，可保存私有审查记录；没有运行目标代码、修复、委派、联网或发布权限。用户明确决定可作为业务依据。

## 材料

独立契约 U1：查询最多 100 个 ID，返回同租户、相同顺序的结果。批量客户端与旧单条客户端使用同一认证及错误约定。

q1 每个 ID 发起一次同步远程调用；q2 一次将最多 100 个 ID 交给现有批量接口。该接口单次完成全部查询，并按输入顺序返回；无重试、分页或隐藏逐项远程调用。典型请求为 80 个 ID。当前授权调用方和响应路径均未改变。

项目另外有搜索缓存和备份服务，这次没有变化，不被上述查询调用，也不承担它的性能或接口保证；其内部实现未提供。本轮相关成本和直接依赖已完整给出，没有实测时间数据。
